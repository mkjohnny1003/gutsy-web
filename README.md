# GUTSY / 腸腸久久

> Eat big. Regret slowly. / 吃得下，不一定消化得了

一款以初代掌機點陣風格呈現的貪食蛇變體。核心差異是**成長延遲**：吃下食物不會立刻變長，食物在蛇身形成腫塊、隨身體後移、消化完成後才結算長度；胃有容量上限，撐爆即死。

這份網頁版是單一 HTML 檔案、無任何相依套件，直接用瀏覽器開啟 `index.html` 就能玩（桌機用鍵盤方向鍵/WASD，手機用螢幕滑動或畫面上的虛擬按鍵）。

## 已完成的內容

- 240×216 邏輯解析度、8 階／4 階（原廠 DMG 規格）雙調色盤，SELECT 鍵切換
- 5 種戰術道具：毒藥、溜冰鞋、炸彈、鑽石（無敵）、消化酵素
- 3 個可玩世界（母關卡），每個世界固定 10 個子關卡：
  - World 1 — 經典原始貪食蛇，無障礙物
  - World 2 — 沙漠，隨機冒出的仙人掌障礙物
  - World 3 — 磚塊世界，經典七種方塊造型障礙物（逐格碰撞判定，不是外框矩形）
- 障礙物有生成預警、20 秒存活期限，過期會消失並在新位置重新冒出
- 三段難度（EASY / NORMAL / HARD）
- 兩種遊戲模式：標準模式（循序解鎖進度）／地圖模式（直接挑任何已開放的世界＋子關卡開玩，不影響標準模式存檔）

## 跟 iOS 原生版的差異

這份網頁版是 iOS 原生版（另外開發中）的行為同步版，規則、數值、關卡設計都一致。唯一刻意簡化的地方：原生版有合成的 chiptune 背景音樂與實體遊戲手把支援，網頁版只有方波音效、沒有背景音樂。
