# GUTSY / 腸腸久久 (GUTSY: Stomach Capacity)

> **Eat big. Regret slowly. / 吃得下，不一定消化得了**

一款以初代復古掌機點陣風格呈現的貪食蛇變體遊戲。  
核心差異在於**「延遲成長（Delayed Growth）」**：吃下食物不會立刻變長，食物會在蛇身內形成腫塊、隨步伐向後推進、經過消化時間後才結算長度；胃部有容量上限，暴飲暴食撐爆即死！善用瀉藥、酵素等道具能逆轉危機。

本倉庫為**網頁純前端版本（Web Prototype）**，以單一 HTML 檔案實作、無任何第三方相依套件，可直接使用現代瀏覽器開啟遊玩。

## 🕹️ 網頁試玩版特色

網頁版為輕量化 Web 原型，供玩家快速體驗前 3 個世界的完整規則：

- **240×216 邏輯解析度**：支援 8 階綠調色盤與原廠 4 階調色盤（SELECT 鍵切換）。
- **5 種戰術道具**：瀉藥/毒藥（縮身排空）、溜冰鞋（調節速度）、炸彈、鑽石（無敵護盾）、消化酵素（瞬間加速消化）。
- **開放 3 個可玩世界（共 30 個子關卡）**：
  - **World 1** — 經典原始場地，熟悉消化與走位節奏。
  - **World 2** — 仙人掌荒漠，隨機冒出剪影障礙物。
  - **World 3** — 磚塊世界，經典 7 種俄羅斯方塊障礙（逐格精確判定，具 20 秒時效刷新）。
- **雙遊戲模式**：標準闖關模式（存檔循序推進）與地圖模式（MAP MODE，自由選關）。
- **操作方式**：
  - 桌機瀏覽器：方向鍵 / WASD 轉向，空白鍵 / Enter 作為 A 鍵，P / B 鍵暫停。
  - 行動裝置：支援螢幕滑動或虛擬掌機按鍵操作。
